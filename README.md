# CoTeach 师生多智能体协同教学系统

老师上课把课讲完，其余的事交给 AI 助教：答疑、布置和批改作业、讲评、看学生卡在哪、备下一节课。老师只在要拍板的时候点一下。

## 能做什么

**老师**

- **CoT 助教**：说一句话就办，比如「给计科2501 布置第四章作业，下周五交」「张浩然那题改成 25 分」「第三章交了几个人」。办完的事能撤回；拿不准的用选项卡片问老师。
- **知识库和整理助手**：老师交的 PDF、PPT、Word、图片、压缩包，整理助手读出来、整理成笔记，原件只读留着。它改了什么像 Word 修订一样显示，说「改回去」就撤回。
- **专门助手**：同一类活反复出现时，助教自己分出一个专门助手，它的会话一直留着、下次接着用；作业可以交给它批，老师改过的分它记得。老师在助教页能看到、能停用。
- **班级**：加课码和二维码，学生自己加入。班里分四栏：
  - 作业：布置、交、批、退回重交；
  - 学情：学生卡在哪几个知识点，丢分多的在前，下节课怎么讲；
  - 成绩：成绩册，导出 Excel；
  - 成员。
- **批改和讲评**：助教照评分标准一项一项给分，在学生原文上划出问题。老师改了一份的某一项，同样问题的其他份可以一起改。讲评能下载 Word，也能发给学生。
- **备课**：挑一个班点「备下节课」，助教照老师知识库里的教案、课件和这个班的学情写下一节课的教案，能下载 Word。

**学生**

- **CoT 学伴**：照班级资料包答疑，自己的作业、截止、分数现查。拿不准的去问老师的助教；要老师定的事（晚交、改分、请假），在老师那边弹一张卡片，老师回了再转告学生。
- **班级**：作业、成绩、成员。
- **错题本**：各个班丢了分的题。点「练一练」，学伴照这道题出一道类似的新题，学生做完帮着判。

## 几个智能体怎么分工

| 谁 | 做什么 | 代码 |
|---|---|---|
| CoT 助教（老师的） | 跟老师对话，用工具办班级、作业、成绩、通知、学情的事 | `server/src/assistant/runtime.ts`、`tools.ts` |
| 整理助手 | 在后台整理老师的知识库：读、写、改、挪、删，交改动 | `server/src/kb/agent/`、`kb/keeper.ts` |
| CoT 学伴（学生的） | 答学生，拿不准问助教 | `server/src/assistant/buddy.ts` |
| 助教的另一手 | 替老师回学伴、写班级资料包；要老师拍板的弹卡片 | `server/src/assistant/helper.ts`、`bridge.ts` |
| 批改、讲评、学情、备课 | 后台的活，照评分标准、照知识库写 | `server/src/grading/` |

要准的东西都由程序算，不交给模型：总分、几个人交了、几个人丢分、截止日期、谁能看到什么。学生看不到答案、试卷、成绩册和别人的作业，这些也由程序拦住，不靠提示词。

模型：默认是服务器上的 Gemini 4 Hydrogen（`CT_AGY_URL`），出错或一直没动静就换 DeepSeek V4.1 Flash。只配 DeepSeek 也能完整运行。

## 10 分钟复现

要先装好这几样（括号里是检查的命令）：

- Node.js 24 或更新（`node -v`）
- pnpm 10（`pnpm -v`，没有就 `npm i -g pnpm`）
- Git（`git --version`，知识库的历史版本存在 Git 里）
- 一个 DeepSeek 开放平台的 API key

```bash
git clone <仓库地址> coteach
cd coteach
pnpm install
cp server/.env.example server/.env
```

打开 `server/.env`，在 `CT_BOOT_DEEPSEEK_KEY=` 后面填上 key。然后开两个终端：

```bash
pnpm dev:server
```

```bash
pnpm dev:web
```

浏览器打开 http://localhost:5190 ：

1. 点「注册」，用手机号建一个老师账号（本地不发短信）。
2. 新建班级，记下加课码；另开一个浏览器（或无痕窗口），用加课码注册一个学生加进来。
3. 老师那边跟 CoT 助教说「给这个班布置一份作业：用 for 循环求 1 到 100 的和，满分 10 分，明天交」；学生那边交作业，等助教批完看分数和批注；学生在 CoT 学伴里问问题。

想直接看一个满的班：在 `server/data/` 里放一个 `seed-demo.json`，内容写 `{"teacher":"<老师的手机号>"}`。半分钟内会自动建好「计科2501 Python 程序设计」：36 个学生、4 份作业，答卷由真模型批改，再写讲评、让几个学生问学伴。大约 10 分钟，要花一点模型调用费。

检查：

```bash
pnpm typecheck
pnpm test
```

`pnpm test` 有 200 多条，不调模型（模型的回答是测试里写好的）。

## 环境变量

都在 `server/.env.example` 里，常用的：

| 变量 | 做什么 |
|---|---|
| `CT_BOOT_DEEPSEEK_KEY` | 第一次启动时接入 DeepSeek，所有助手默认用它 |
| `CT_AGY_URL` | 可选：Gemini 接口（OpenAI 写法），设了就当默认模型，DeepSeek 当备用 |
| `CT_DATA_DIR` | 可选：数据放哪，默认 `server/data` |
| `CT_PORT` | 可选：后端端口，默认 18660 |

第一次启动会建超级管理员 `root`，密码写在 `server/data/root-password.txt`，在「管理」里能开关老师注册、看模型调用。

## 怎么知道助手做得好不好

改发给模型的每一句话之前先量，量完对比，记在 [提示词账.md](提示词账.md)：量了什么、改前改后各多少、改了哪句、删过哪些话。

量用的是 `tools/` 里的尺子，跑真模型，要花钱：

| 尺子 | 量什么 |
|---|---|
| `tools/ta-measure` | 老师跟助教说的 61 句：办对没有、该问没问、不该问问了 |
| `tools/stu-measure` | 学生跟学伴说的 34 句：答对没有、有没有漏给答案、该转老师的转没转、卡片多长 |
| `tools/grade-measure` | 8 份好坏分明的答卷各批两遍：分数落没落在该落的段、两遍差多少、有没有漏出参考答案 |
| `tools/grade-map` | 演示班 70 份答卷：交分有没有交错题 |

在 `server` 目录跑，比如 `node --import tsx ../tools/grade-map/ruler.ts 标签`，结果在 `output/` 里。
