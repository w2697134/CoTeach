# CoTeach（重做版）

师生多智能体协同教学系统的重做版，2026-11-05 开始。旧版在 `projects/teach-v2`，线上 teach.haovio.com 目前跑的仍是旧版。

方向是“鸣琴垂拱，不言而化”：给每个老师配一个越用越熟的 AI 助教。老师只管讲课，知识库有变化时跟它说一声；助教靠读老师的教案认识老师，拿不准就问老师，问过的记住。

## 现在有什么

第一个功能：知识库和整理助手。

- 每门课一个知识库，老师交资料（Word、PPT、PDF、Markdown、TXT、代码文件），整理助手读完整理成笔记，补全目录、进度、规矩。
- 整理助手写的东西不会马上生效，作为一次改动交给老师确认；老师看前后对比，点确认或不要。生效后的改动随时可以撤回。
- 老师可以直接改知识库里的任何文字文件，改完马上生效，也能撤回。
- 可以跟整理助手说话：让它改（“第7章讲完了”“规矩里加一条……”），或者问它知识库里有什么。
- 整理助手读了什么、写了什么、说了什么都记在工作记录里，干活时页面上实时显示。

## 本地运行

```bash
pnpm install
```

`server/.env` 里写 `CT_BOOT_DEEPSEEK_KEY=...`（第一次启动时接入 DeepSeek V4.1 Flash），然后分别启动：

```bash
pnpm dev:server
```

```bash
pnpm dev:web
```

后端 127.0.0.1:18660，前端 http://localhost:5190，登录页有演示老师一键登录。

## 代码在哪

- `server/src/kb/repo.ts`：每门课的知识库是一个 git 仓库（`server/data/kb/<课程 id>`）。读写文件、提交、历史、撤回都在这里，同一门课的操作排队执行。
- `server/src/kb/changes.ts`：改动的生成、确认、不要、撤回、对比。
- `server/src/kb/keeper.ts`：整理助手。给模型的交代、工具、暂存区、工作记录都在这里。
- `server/src/kb/convert.ts`：资料转文字。`diff.ts`：给前端的对比。`routes.ts`：接口。
- `web/src/pages/kb/`：知识库页面（左目录、中间看和改、右边整理助手，改动在抽屉里）。
- `tools/kb-measure/`：量整理助手的脚本和测试资料。

## 知识库的规矩

- 最上层固定：`目录.md`、`进度.md`、`规矩.md`、`资料/`（老师交的原件和转出来的文字，整理助手只读）、`笔记/`（怎么分随老师资料原来的分法）。
- 每次生效都是一次 git 提交，提交信息里写着改动编号。作者是写内容的人（整理助手或老师），提交人是确认的人。
- 整理助手的改动等老师确认；老师自己改、交资料直接生效；只挪文件、改目录的算纯整理，也直接生效。
- 这一届学生的情况（名单、成绩）不进知识库，知识库是年年用的。
