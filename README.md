# CoTeach

给每位老师配一个逐渐熟悉其教学方式的助教。老师讲课，资料或教学安排有变化时告诉整理助手；整理助手负责把有依据的知识组织好。

## 知识归属

- 每位老师一份长期知识库。课程仍保留在原首页，但不再各自建立知识库。课程资料、教学方式、约定和批改尺度由整理助手自由组织，没有固定目录骨架。
- 每个班级每个学期一份临时知识库，保存进度、安排和学情。学生个人记录以名单中的稳定身份单独归属，移动文件不会改变可见范围。
- 原件及转换文字保存在老师专属档案区，原文不允许覆盖。老师和整理助手可以查阅、调整展示位置或移除引用；原始版本和历史保留。其他助手不能读取这些档案。
- 长期库的助手内容修改须老师确认；内容和权限不变的明确移动直接生效。修改目录文档里的正文也属于内容修改。老师亲自编辑直接生效，但同样经过隐私和原文保护检查。
- 班级修改直接生效、留记录、可撤回。封存学期后只读，停止未完成任务，自动排入经验提炼工作；有依据的长期提案仍须老师确认。

学生姓名、别名、学号以及原文明确列出的学生身份词，在写入和读取投影处检查。该检查覆盖已登记身份，不声称能百分之百识别任意未登记的人名。名单归属、班级范围、个人记录和原件隔离由代码保证，不依赖模型遵守提示词。

## 使用

首页「我的课程」保留。导航「我的知识库」提供长期库、班级与学期入口。新建班级需填写真实班级和学期，学生名单可随后添加，不会自动生成学生。

知识库可交资料、与整理助手对话，也可自行新建、编辑、移动、移除笔记。改动以文档修订稿呈现，可确认、不要或撤回。资料上传后自动整理；助手忙时排队，失败后保留重试入口。封存班级只保留阅读、历史与经验提炼入口。

## 本地开发

```powershell
pnpm install
pnpm dev:server
pnpm dev:web
```

后端默认 `127.0.0.1:18660`，前端 `http://localhost:5190`。演示老师入口沿用。首次接入模型通过 `server/.env` 的 `CT_BOOT_DEEPSEEK_KEY` 设置；不要把 key 写进命令行或工作记录。整理助手仅使用 DeepSeek V4.1 Flash（`deepseek-flash`），不可用时明确报错，不自动改用别的模型。

开发副本通过 `CT_DATA_DIR` 指定。一个数据目录只允许一个写进程，服务或迁移程序同时启动会被拒绝；SQLite 操作系统锁随进程退出释放，不依赖 PID。应用启动会恢复已完成但尚未整理 Git 引用的提交，并标记中断任务。`check` / `verify` 仅在临时副本打开数据库，不给原库升表或创建辅助文件。

```powershell
pnpm typecheck
pnpm test
pnpm build
```

构建产物包括 `server/dist/server.mjs`、前端资源和独立迁移工具 `server/dist/kb-owner.mjs`。迁移、核验和回退流程见 [MIGRATION.md](MIGRATION.md)。生产部署只由 Claude 执行。

## 实现入口

- `server/src/kb/access.ts`：归属、名单及身份检查。
- `repo.ts`：逻辑文件身份、受保护原件、Git 版本和发布指针。新仓库使用独立索引生成完整版本，SQLite 事务发布后才可见。
- `changes.ts`：确认、冲突、重复请求、撤回及文档修订内容。
- `workspace.ts`：固定任务开始时的版本，按文件身份暂存创建、改写、移动与删除。提交时同时核验身份和内容，过期任务不能覆盖老师的新修改；移动并改写仍属于需要确认的内容修改。
- `keeper.ts`：整理助手、任务队列和学期提炼。
- `evidence.ts` / `experience.ts`：学期提炼先仅从本班封存资料核对经验和引用原句，再由助手选择长期文档及章节；存放时保留已核对文字并生成真实出处，避免第二次自由改写扩大范围。没有经验时不创建提案；普通对话和资料整理仍可自由编辑。
- `reader.ts`：其他助手的唯一知识读取入口和观察提交入口。只读已发布内容，按服务器绑定的班级及学生身份过滤；不提供原件、Git、历史或教师工作记录。
- `migrate.ts` / `inspection.ts`：归属迁移、只读预检查和完整性核验。
- `web/src/pages/kb/`：知识库、班级与名单、文件操作和改动页面。
- `server/tests/`：权限、生命周期、故障恢复与迁移测试，均使用独立测试数据。
- `tools/kb-measure/`：真实模型测量，测试 URL 限本机；先查余额，测试数据限独立副本。

旧目录、进度、规矩、笔记、资料在迁移中保持原文；重新整理由老师与整理助手以后决定。原教案「计科2301班」只保留为来源标注，学期待指定，不据此创建班级。旧工作事件已经缺失的部分不补造。
