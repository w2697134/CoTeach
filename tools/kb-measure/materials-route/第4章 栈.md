# 第4章 栈

## 4.1 什么是栈

栈是只能在一端插入和删除的线性表。能操作的一端叫栈顶，另一端叫栈底。最后放进去的元素最先拿出来，叫后进先出（LIFO）。生活里的例子：一摞盘子，只能从最上面放、从最上面拿。

## 4.2 基本操作

- 入栈 push(x)：把 x 放到栈顶。
- 出栈 pop()：拿走并返回栈顶元素，栈空时出栈要报错（下溢）。
- 取栈顶 peek()：只看不拿。
- 判空 is_empty()。

## 4.3 两种实现

顺序栈用数组存，用一个变量 top 记栈顶位置。Python 里直接用列表：`append` 入栈，`pop()` 出栈，都在列表尾部，时间 O(1)。

```python
class Stack:
    def __init__(self):
        self.items = []
    def push(self, x):
        self.items.append(x)
    def pop(self):
        if not self.items:
            raise IndexError('栈是空的')
        return self.items.pop()
    def peek(self):
        return self.items[-1]
    def is_empty(self):
        return not self.items
```

链栈用单链表存，表头当栈顶，入栈出栈都在表头做，不用担心空间不够。

## 4.4 栈的应用

1. 括号匹配：从左往右扫表达式，遇到左括号入栈，遇到右括号就出栈看是否配对；扫完栈要为空。
2. 函数调用：每调用一次函数，系统把这次调用的参数、局部变量和返回地址压进调用栈；函数返回时弹出。递归太深会栈溢出，就是这个栈放不下了。
3. 表达式求值：中缀表达式先转成后缀表达式，再用一个栈求值。

讲括号匹配时，先让学生手工演示 `([)]` 为什么不合法：扫到 `)` 时栈顶是 `[`，配不上。
