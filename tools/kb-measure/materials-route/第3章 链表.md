# 第3章 链表

## 3.1 为什么需要链表

顺序表（数组）在内存里占一整块连续空间，按下标取元素很快，但在中间插入、删除元素时，后面的元素都要挪动，平均要挪 n/2 个。元素个数事先不好估计时，数组还要整体扩容、搬家。

链表换了一种存法：每个元素单独放在一个结点里，结点除了存数据，还存一个指向下一个结点的引用。结点在内存里可以东一个西一个，靠引用串成一条链。

## 3.2 单链表

单链表的结点有两部分：数据域 data 和指针域 next。第一个结点由头指针 head 指向，最后一个结点的 next 为空。

```python
class Node:
    def __init__(self, data, next=None):
        self.data = data
        self.next = next
```

为了让插入、删除在表头和表中间写法一致，常在第一个数据结点前放一个不存数据的头结点（哑结点）。

## 3.3 基本操作

- 查找第 i 个元素：只能从头沿 next 往后数，时间 O(n)。
- 在结点 p 后面插入新结点 s：先 `s.next = p.next`，再 `p.next = s`。两句顺序不能反，反了会把后面的链弄丢。
- 删除结点 p 后面的结点：`p.next = p.next.next`。
- 求表长：从头走到尾，边走边数。

课堂上让学生在纸上画出插入前后每个引用指向哪里，再写代码。插入两句写反是最常见的错误。

## 3.4 双链表和循环链表

双链表的结点多一个 prior 指针指向前一个结点，从任一结点都能往前往后走，删除某个结点时不用再找它的前驱。循环链表把最后一个结点的 next 指回头结点，从任意结点出发都能走遍全表。

## 3.5 链表和数组怎么选

| 比较项 | 数组 | 链表 |
|---|---|---|
| 按位置取元素 | O(1) | O(n) |
| 已知位置插入删除 | O(n)，要挪元素 | O(1)，只改引用 |
| 空间 | 连续，可能要扩容 | 分散，每个结点多存一个引用 |

按位置读多、改少用数组；经常在中间插入删除、元素个数变化大用链表。
