# 第6章 函数基础

## 6.1 为什么需要函数

函数是一段有名字、可重复调用的代码。它能：

- **复用**：写一次，到处调用；
- **抽象**：调用者只需知道「做什么」，不必关心「怎么做」；
- **分解**：把大问题拆成小问题，每个函数只做一件事，便于测试和调试。

## 6.2 定义与调用

```python
def area(width, height):
    """计算矩形面积"""          # 文档字符串，说明函数用途
    return width * height

print(area(3, 4))   # 12
```

- `def` 定义函数，函数名后是**形参**列表，调用时传入的是**实参**。
- `return` 结束函数并返回结果；没有 return（或 `return` 后面为空）时返回 `None`。
- 函数必须**先定义后调用**。

### return 与 print 的区别

```python
def add1(a, b):
    print(a + b)     # 只是显示在屏幕上

def add2(a, b):
    return a + b     # 把结果交给调用者

x = add1(1, 2)       # 屏幕显示 3，但 x 是 None
y = add2(1, 2)       # 屏幕不显示，y 是 3
```

> **高频错误**：函数里用 `print` 代替 `return`，导致调用者拿到的是 `None`，出现 `TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'`。

### 返回多个值

```python
def min_max(nums):
    return min(nums), max(nums)   # 实际返回一个元组

lo, hi = min_max([3, 9, 1])
```

## 6.3 参数的几种形式

```python
def greet(name, greeting="你好", *args, punctuation="！", **kwargs):
    ...
```

| 形式 | 说明 | 示例 |
| --- | --- | --- |
| 位置参数 | 按位置对应 | `area(3, 4)` |
| 关键字参数 | 按名字传递，顺序无关 | `area(height=4, width=3)` |
| 默认参数 | 定义时给默认值，调用时可省略 | `def greet(name, greeting="你好")` |
| 可变参数 `*args` | 接收任意多个位置参数，打包成元组 | `def total(*nums): return sum(nums)` |
| 关键字可变参数 `**kwargs` | 接收任意多个关键字参数，打包成字典 | `def info(**kw): print(kw)` |

> **默认参数陷阱**：默认值只在定义时计算一次。不要用可变对象（如 `[]`）作默认值：
> ```python
> def add_item(x, items=[]):   # 错误示范
>     items.append(x)
>     return items
> add_item(1); print(add_item(2))   # [1, 2]，上一次的结果被保留了！
> ```
> 正确写法：`def add_item(x, items=None): if items is None: items = []`。

## 6.4 参数传递：传的是「引用」

Python 中参数传递传的是对象的引用。效果取决于对象是否可变：

```python
def change(n, lst):
    n = n + 1          # 让局部变量 n 指向新对象，不影响外部
    lst.append(99)     # 修改了传入的列表对象本身，外部可见

a, b = 1, [1, 2]
change(a, b)
print(a, b)   # 1 [1, 2, 99]
```

- 不可变对象（int、str、tuple）：函数内「修改」其实是创建了新对象，外部不受影响。
- 可变对象（list、dict、set）：在函数内调用 `append` 等方法会改变外部对象。

## 6.5 变量作用域

- **局部变量**：在函数内部赋值的变量，只在函数内有效，函数结束后消失。
- **全局变量**：在函数外定义，整个文件都能读取。
- 查找顺序遵循 **LEGB** 规则：Local（局部）→ Enclosing（外层函数）→ Global（全局）→ Built-in（内置）。

```python
count = 0
def increase():
    count += 1      # UnboundLocalError！
```

报错原因：函数内对 `count` 赋值，Python 就把它当作局部变量，而此时局部的 `count` 还没有值。若确实要修改全局变量，需要声明 `global count`。但更好的做法是**通过参数传入、通过返回值传出**，尽量少用全局变量：

```python
def increase(count):
    return count + 1
count = increase(count)
```

## 6.6 函数设计的好习惯

1. 一个函数只做一件事，函数名用动词短语：`calc_average`、`is_valid`。
2. 用文档字符串说明参数与返回值。
3. 函数内不要依赖 `input()` 和 `print()`，让它通过参数和返回值与外界交流——这样才方便测试和复用。
4. 写完函数立刻用几组数据测试，包括边界情况（空列表、0、负数）。

## 6.7 本章小结

- `return` 把结果交给调用者，`print` 只是显示；没有 return 的函数返回 `None`。
- 默认参数不要用可变对象。
- 可变对象作参数时，函数内的原地修改会影响外部。
- 函数内赋值的变量是局部变量；少用 `global`，多用参数和返回值。
