# 常见错误与调试技巧手册

本手册整理了本课程学生最常遇到的错误，按报错类型组织。遇到问题时先对照查找，还解决不了再问 AI 助教。

## 一、怎么读报错信息

```text
Traceback (most recent call last):
  File "main.py", line 3, in <module>
    total = total + score
TypeError: unsupported operand type(s) for +: 'int' and 'str'
```

1. **看最后一行**：异常类型 `TypeError` + 具体原因（int 和 str 不能相加）。
2. **找行号**：`line 3` 告诉你出错的位置。
3. **想数据**：出错那一行里每个变量此刻的值和类型是什么？可以在出错行前面加 `print(repr(变量), type(变量))`，或使用「执行可视化」查看。

## 二、按错误类型速查

### TypeError

- **`can only concatenate str (not "int") to str`**：字符串和数字直接用 `+` 连接。解决：`str(n)` 或使用 f-string。
- **`unsupported operand type(s) for +: 'int' and 'str'`**：`input()` 的结果没转成数字。
- **`'NoneType' object is not subscriptable` / `... for +: 'NoneType'`**：拿到了 `None`。最常见的两个原因：
  1. 函数里用了 `print` 而不是 `return`；
  2. 写了 `a = a.append(x)` 或 `a = a.sort()`。
- **`'int' object is not iterable`**：`for i in n:` 应写成 `for i in range(n):`。

### IndexError: list index out of range

- 循环写成了 `range(len(a) + 1)` 或 `range(1, len(a) + 1)` 后用 `a[i]`。
- 空列表取 `a[0]`、`a[-1]`。

### KeyError

字典中没有这个键。先用 `in` 判断，或改用 `d.get(key, 默认值)`。

### ValueError: invalid literal for int() with base 10

`int()` 收到了不是整数的字符串，比如 `"3.5"`、`""`（直接回车）或 `"3 4"`（一行两个数）。读一行多个数用 `map(int, input().split())`。

### IndentationError / SyntaxError

- 冒号后面的代码块缩进不一致（混用了 Tab 和空格），统一使用 4 个空格。
- `if`、`for`、`def` 行末忘记冒号。
- 中文标点：`print（"hi"）` 中的中文括号、中文引号都会导致语法错误。

### UnboundLocalError

函数内部给一个与全局变量同名的变量赋值（如 `count += 1`），Python 把它当作局部变量。解决：通过参数传入并返回新值。

### RecursionError: maximum recursion depth exceeded

递归没有终止条件，或者递归调用没有向终止条件靠近。检查：出口条件是否覆盖了所有最小情况？每次递归参数是否在变小？

## 三、逻辑错误（程序不报错但结果不对）

| 现象 | 可能原因 |
| --- | --- |
| 循环少执行一次 | `range(1, n)` 取不到 n，应为 `range(1, n + 1)` |
| 程序卡住不动 | `while` 死循环，循环变量没有更新 |
| 累加结果不对 | 累加变量在循环**内部**被初始化了 |
| 列表删元素漏删 | 遍历列表的同时删除元素 |
| 两个列表「同步变化」 | `b = a` 只是引用，需要 `a.copy()` |
| 浮点比较失败 | `0.1 + 0.2 != 0.3`，改为比较差值 |
| 整除结果不对 | 用了 `/`（结果是浮点数）而不是 `//` |

## 四、调试方法

1. **打印调试**：在关键位置打印变量，推荐 `print(f"{i=}, {total=}")` 这种写法，会同时显示变量名和值。
2. **缩小范围**：把代码一段段注释掉，定位出错的最小片段。
3. **执行可视化**：在「代码实验室」中逐步执行，观察每一步变量和调用栈的变化，特别适合理解循环和递归。
4. **小数据手算**：用最小的输入（如 n = 1、n = 2）手算预期结果，和程序输出对比。
5. **橡皮鸭调试法**：把代码逐行讲给别人（或 AI 助教）听，讲着讲着往往就发现问题了。

## 五、提交作业前的自查清单

- [ ] 用题目给的样例测试过，输出格式（空格、换行、标点）与样例完全一致；
- [ ] 测试过边界情况：最小输入、空输入、相同数据、负数；
- [ ] 没有多余的提示文字（如 `input("请输入：")` 中的提示在评测时会被当作输出）；
- [ ] 变量命名见名知意，关键步骤有注释。
