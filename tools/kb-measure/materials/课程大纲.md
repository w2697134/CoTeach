# 《Python 程序设计》课程大纲

## 一、课程基本信息

| 项目 | 内容 |
| --- | --- |
| 课程名称 | Python 程序设计 |
| 课程性质 | 专业基础课（必修） |
| 适用专业 | 计算机科学与技术、软件工程 |
| 学分 / 学时 | 3 学分 / 64 学时（理论 32 + 实验 32） |
| 先修课程 | 计算机导论 |
| 后续课程 | 数据结构与算法、数据库原理、人工智能导论 |

## 二、课程目标

1. **知识目标**：掌握 Python 的基本语法、数据类型、控制结构、函数、文件与异常、面向对象等核心知识。
2. **能力目标**：能够分析简单的实际问题，设计算法并用 Python 编写结构清晰、可运行、可测试的程序；具备阅读报错信息和调试程序的能力。
3. **素养目标**：养成规范命名、写注释、先测试再提交的工程习惯；在小组实验中学会合作与表达；树立学术诚信意识。

## 四、考核方式

- 平时作业（在线提交，AI 初评 + 教师复核）：30%
- 课堂互动与出勤：10%
- 实验报告：20%
- 期末机考：40%

## 五、学习建议

1. **多动手**：每个知识点都在「代码实验室」里亲手跑一遍，改一改参数看看结果怎么变。
2. **会调试**：遇到报错先读最后一行的错误类型和行号，再用「执行可视化」一步步看变量怎么变化。
3. **善用 AI 助教**：卡住时先说说自己的思路，再请小灵助教给提示；作业期间助教只提供思路引导，不会直接给出答案。
4. **重视错题**：错题本会自动收录做错的题目，定期用「举一反三」巩固。
