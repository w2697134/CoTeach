第5章 字符串处理（讲义）

Python 程序设计 · 第 4 周 · 2 学时

5.1 先认识字符串：一串不能改的字符

字符串用单引号、双引号或三引号写，三引号可以跨行。字符串是不可变的：写 s[0] = "x" 会报 TypeError，要“改”只能拼出一个新的字符串。

下标和切片：s[0] 取第一个字符，s[-1] 取最后一个，s[2:5] 取第 3 到第 5 个，s[::-1] 整串倒过来。

例 5-1 学号拆分：班里的学号写成“年级-座号-姓名”。

stu_code = "2505-07-陈思远"
grade, seat, name = stu_code.split("-")
print(name, "坐第", int(seat), "号")   # 陈思远 坐第 7 号

5.2 常用方法分三组：查、改、判

查：find、index、count、startswith、endswith。find 找不到返回 -1，index 找不到直接报错。

改：upper、lower、title、replace，还有去空白的“strip 三兄弟”：strip、lstrip、rstrip。

判：isdigit、isalpha、isspace，返回 True 或 False。

例 5-2 手机号打码：

def mask_phone(phone):
    phone = phone.strip()
    return phone[:3] + "****" + phone[-4:]

print(mask_phone(" 13812345678 "))   # 138****5678

易错点：replace 不会改原来的字符串，要把结果接住：s = s.replace("a", "b")。

5.3 拼接与拆分：join 和 split 是一对

"-".join(["2505", "07"]) 得到 "2505-07"；"2505-07".split("-") 又拆回列表。大量拼接用 join，不要在循环里写 +=，每次 += 都会新建一个字符串。

例 5-3 课程表一行：

week = ["周一", "周三", "周五"]
print(" / ".join(week))   # 周一 / 周三 / 周五

5.4 格式化输出：f-string 和对齐

f"{name}的成绩是{score}"。对齐写在冒号后面：{name:<6} 左对齐占 6 格，{score:>6.1f} 右对齐保留一位小数，{rank:^4} 居中占 4 格。

例 5-4 成绩条对齐打印：

rows = [("陈思远", 92.5, 1), ("李一诺", 88, 2)]
for name, score, rank in rows:
    print(f"{name:<6}{score:>6.1f}{rank:^4}")

易错点：一个中文字符在终端里占两个英文字符宽，名字有中文时对不齐，可以用全角空格补。

5.5 综合练习：回文判断和词频统计

例 5-5 回文判断：先只留字母和数字、统一成小写，再和倒过来的比。

def is_palindrome(text):
    clean = "".join(ch.lower() for ch in text if ch.isalnum())
    return clean == clean[::-1]

例 5-6 英文句子词频（大小写归一）：

sentence = "To be or not to be"
words = sentence.lower().split()
freq = {}
for w in words:
    freq[w] = freq.get(w, 0) + 1
